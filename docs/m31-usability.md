# M31 usability evidence

Status: pending external evidence.

M31 must recruit a five-person cohort for early M32 interface feedback before
M31 closes. This is a design-validation activity, not evidence that M31 has
passed its runtime gates.

## Required protocol

Each participant should attempt the ordinary golden path: understand a
scoped rule, inspect applicability, validate or preview it, deploy it, run it,
inspect status and explanation, and diagnose a blocked or stale source. The
participant should not need private catalogs, internal UUIDs, milestone
history, or maintainer interpretation.

Record for each participant:

- task outcome and transcript or prototype feedback;
- questions, wrong turns, and terminology confusion;
- whether the participant needed undocumented help;
- exact repeated issues and their proposed disposition.

Any issue encountered by at least two of five participants must be fixed before
the relevant release or recorded as a concrete M32 release blocker. The
repository currently contains no cohort roster, transcripts, or results, so
the usability gate is not verified.
