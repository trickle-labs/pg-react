# M31 readiness

**Status: implementation and local qualification complete; release not yet
qualified.**

M31 is the **Authoritative runtime** milestone. The working tree packages the
M31 runtime as extension `0.28.0` and preserves the released M30 foundation at
`0.27.0`. It must not reuse or move the existing `v0.27.0` tag.

## Verified locally

`tests/m31.sh fast` and `tests/m31.sh complete` pass against a rebuilt
`linux/amd64` image. The complete lane covers:

- authoritative rule, decision-program, and policy-set behavior;
- entry, exit, return, expiry, removal, overlap, support transitions, and
  claimed-work revalidation;
- fail-closed invalid, unauthorized, malformed, incomplete, drifted, RLS, and
  over-limit sources;
- role isolation, bounded performance, retention, and two-session race/lease
  behavior;
- inherited M0–M30 qualification, populated upgrade, crash/restart, logical
  restore, standby promotion, and physical restore.

Rust formatting and the no-default-features Rust test suite also pass. The
logical-restore fixtures are exercised by `tests/m6-recovery.sh` when the M31
recovery profile is selected.

## Remaining release gates

The executable lane is green, but the M31 plan also requires evidence that
cannot be honestly generated by a local test run:

- recorded early feedback from the five-person M32 usability cohort;
- the complete release-artifact, documentation-example, rollback, and
  qualification record required by [m31-evidence.md](m31-evidence.md).

Until those records exist, M31 is an implementation candidate rather than a
published release. Do not publish a release tag just to make the status appear
green.

## Versioning and next milestone

The M31 package identity is **`0.28.0`**, not `0.27.0`. Once every gate is
green, update release evidence together, then tag and push `v0.28.0`.

The logical next milestone is **M32 — PostgreSQL-native interface**, planned
for extension `0.29.0`. It is defined in [ROADMAP.md](../ROADMAP.md), but its
entry gate is a qualified M31, so only preparation—not M32 feature freeze—
should begin now.
