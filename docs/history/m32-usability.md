# M32 human usability record

## Required external exercise

M32 requires five PostgreSQL developers who did not implement the tested API
to follow the README first-rule workflow without maintainer intervention.

The frozen targets are:

- median time from opening the guide to the first effective match: 15 minutes
  or less;
- at least four of five complete without undocumented help;
- nobody uses a private catalog or manually discovers an internal UUID;
- every repeated confusion is recorded and fixed or declared a release blocker.

## Current status

**Pending external evidence.** This repository contains the protocol and the
ordinary workflow, but no participant results, timings, completion rates, or
interview notes. Those must be supplied by a human-led exercise; they cannot be
invented by a documentation or CI change.

The same limitation applies to broader evidence about documentation
comprehension outside the five-person protocol.
