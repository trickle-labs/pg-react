# M11 compatibility matrix for `0.7.0`

This matrix is the complete policy for provisional `0.7.0` surface classes.
The installed `0.7.0` SQL script, its upgrade chain, and `pg-reactd` invocation
named in [the M11 pre-entry fixture](m11-preentry.md) are the exact inventory
within each class. No unlisted identifier is implicitly retained.

`REMOVE` means the old name is unavailable after upgrade. `BRIDGE` means the
upgrade accepts or exposes it only to complete the documented transition.
`RETAIN` means the behavior remains a compatibility commitment. All replacement
commitments begin with the M11 extension and bundled-worker release.

| `0.7.0` class | Policy | M11 replacement or rule |
| --- | --- | --- |
| Public schema `pgreact` | REMOVE | `pgreact_api` is the only public schema. The old schema may remain physically present only as a private implementation detail. |
| Private schemas, runtime relations, generated dispatchers, and catalog identity | RETAIN | Remain non-public engine state; M11 preserves their durable meaning, not names or layout. |
| `activation_context` and typed consequence/outbox signatures | BRIDGE | Existing immutable versions and pending episodes keep their exact dispatch contract. New declarations use the `pgreact_api` authoring contract. |
| Public authoring, lifecycle, refresh, and recovery functions | REMOVE | Name-first `pgreact_api` author and operator concepts replace version-id-first calls. |
| Public pack functions and manifest fields | BRIDGE | M11 accepts the released format-versioned `0.7.0` pack for upgrade and reports diagnostics; new and rewritten packs use the M11 name-first declarations. |
| Public status, match, agenda, attempt, drift, metrics, and evidence views/functions | REMOVE | Versioned name-first status, history, diagnostics, and explanation envelopes in `pgreact_api`; exact identities are advanced inspection only. |
| Public worker claim, lease, execution, batch, and protocol functions | BRIDGE | The M11 worker exposes the inherited protocol-1 and protocol-2 behavior through its worker contract. Legacy calls exist only as needed to drain or recover pre-upgrade work. |
| `pg-reactd` command, environment configuration, and protocol selection | BRIDGE | The M11 worker accepts the documented upgrade configuration and both inherited protocols; unsupported protocol selection stops before claim. |
| Public grants | REMOVE | Re-grant least privilege only on `pgreact_api` author, operator, worker, and reader surfaces; grant nothing to `PUBLIC`. |
| Diagnostic envelopes | RETAIN | The complete versioned diagnostic meaning is retained; a bridge preserves it if presentation names change. |
| Installation, authoring, operations, security, recovery, upgrade, and troubleshooting documentation | REMOVE | M11 task guides use only `pgreact_api`; `0.7.0` guides are historical upgrade references. |

## Migration guarantees

The M11 extension upgrade is the only supported migration path from `0.7.0`.
It preserves normalized durable state and pending or leased work byte-for-byte
where M0--M10 already require it. A removed surface fails with the versioned
diagnostic envelope and a replacement hint; a bridge remains only for the
documented upgrade or work-drain path. No bridge creates a new compatibility
commitment for a provisional `0.7.0` name.
