# M18 release notes — `0.15.0`

M18 hardens production usability, diagnostics, benchmarks, recovery,
operations, documentation, packaging, and upgrade evidence for the complete
M0–M17 product.

There are no new rule-engine semantics and no changes to inherited truth,
lifecycle, ordering, delivery, retry, retention, recovery, or external-effect
guarantees. The direct supported upgrade is `0.14.0 -> 0.15.0`.

The release bundle includes the `linux/amd64` image archive, complete-profile
evidence, SHA-256 checksums plus OCI digest, SPDX 2.3 SBOM, and signed GitHub
artifact/image/SBOM attestation bundles.
