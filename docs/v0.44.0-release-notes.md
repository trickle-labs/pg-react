# pg-react 0.44.0 release notes

pg-react 0.44.0 scopes comparison provenance to the target, its source, and
its current runtime rows. Unrelated declarations, work, and retained history
are no longer part of the comparison no-effect guard.

- Rule-source validation collects total, null-key, duplicate-key, and bounded
  evidence rows from one materialized source scan.
- Existing full-state checksum behavior remains available to non-comparison
  callers; comparison evidence identifies the target-scoped digest.
- Current SQL assembly has an explicit ordered input manifest, and the current
  qualification runner separates static checks from optional Docker evidence.
- No universal throughput or memory guarantee is claimed. The supported
  envelope is the measured workload recorded by `docs/benchmarks.md`.

Upgrade from 0.43.3 with:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.44.0';
```

See the [migration guide](v0.44.0-migration.md), [benchmarks](benchmarks.md),
and [limits](limits.md).
