failed with SQLSTATE 42702 because `worker_id` was ambiguous. The 0.46.2 fresh
install and 0.46.1-to-0.46.2 upgrade both apply the same `CREATE OR REPLACE`

adjacent upgrade. The MDM joint worker-cycle qualification remains required to
