# M43 benchmark

M43 measures declaration normalization, field traversal, collection members,
object lookup, serialization, hashing, returned payload, and elapsed time in
the result cost object. Elapsed time is diagnostic only and never enters the
semantic digest.

The representative qualification profile uses one financial-exception rule,
one access-drift decision program, and one policy set. The supported-limit
profile uses 1,024 fields, 10,000 collection members, 1,024 differences, and a
16 MiB payload ceiling. A bound produces `partial` before an incomplete answer
is presented as complete.
