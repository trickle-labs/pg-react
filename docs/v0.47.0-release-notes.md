# pg-react v0.47.0 read-only policy package

The v0.47.0 adapter package adds the first read-only MDM policy slice:

- authorized projection validation for `MDM-STEWARDSHIP/1` policy cases;
- immutable React-owned policy revisions and contract-compatible digests;
- deterministic route explanations with winner, ambiguous, no-candidate,
  protected, and no-op outcomes;
- elapsed-time deadline previews from immutable occurrence opening times;
- bounded policy comparisons with explicit population coverage and no-effect
  evidence.

The package does not submit MDM intents, write MDM tables, create React work,
advance lifecycle state, or invoke refresh. The core extension version remains
independent because the adapter is optional.

Live qualification passed against the released pg-mdm v0.13.1 source tag
(extension version 0.14.0) on PostgreSQL 18.4. The evidence manifest records
the tested image digests, exact-tag lifecycle checks, restore results, and
read-only state comparison.

The approved pilot envelope is 100 target review cases from 150 loaded source
rows, with a 54-second initial refresh limit and a 4-second limit after one
timestamp-only row update. The measured runs took 53.765 and 3.958 seconds.
A 1,000-case run did not complete within 14 minutes. Production-scale limits,
peak memory, retention, steady-state storage, and production recovery remain
unsupported. The adapter is a source SQL package; the independently versioned
core extension remains at 0.46.0.
