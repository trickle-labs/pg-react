# pg-react 0.44.0 migration

Stop managed and external workers, take a verified backup, and install the
0.44.0 extension files beside the existing 0.43.3 files. Apply the adjacent
update in the same database:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.44.0';
```

Verify `pg_extension.extversion`, run the current qualification corpus, and
resume workers only after the candidate image and SQL artifact match. The
update adds no new public API and does not rewrite historical evidence.

The current installation artifact is assembled from
`sql/current/assembly.txt`; the adjacent script is
`sql/pg_react--0.43.3--0.44.0.sql`.
