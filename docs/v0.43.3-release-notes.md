# pg-react 0.43.3 release notes

pg-react 0.43.3 is the correctness patch over 0.43.2. It keeps healthy work
moving when another job is damaged and aligns retry, lease recovery, and
operator output with durable state.

- Retry delays saturate before numeric multiplication or integer narrowing.
- Direct, batch, and managed execution isolate each claimed job in a
  subtransaction and record drift or dispatcher failures without undoing
  healthy work.
- Name-based lease sweeping covers every authorized active, paused, and
  draining version while preserving the bigint return contract.
- `pgreact.work.claimable` is advisory and reflects due work, barriers,
  conflicts, groups, and activation eligibility. New agenda activity has a real
  `updated_at` timestamp; unknown pre-upgrade history remains NULL.
- Managed status preserves structured blocked coordination causes as `error`
  detail while recording independent job progress.

Upgrade from 0.43.2 with:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.43.3';
```

See the [migration guide](v0.43.3-migration.md) and [upgrade guide](upgrade.md)
for the stopped-cluster backup and verification procedure.
