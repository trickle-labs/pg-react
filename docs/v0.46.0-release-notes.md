# pg-react 0.46.0 release notes

pg-react 0.46.0 qualifies the pg_trickle 0.105.2 public capability boundary
and freezes the approved `MDM-STEWARDSHIP/1` contract fixture.

- The supported runtime is PostgreSQL 18.3, pg_trickle 0.105.2, trigger CDC,
  `READ COMMITTED`, scheduler off, and explicit pg-react coordination.
- Stable, enabled Graph V1 and Delta V1 capabilities are accepted as upstream
  availability. React does not call Graph V1, consume Delta V1, or enable WAL
  CDC, and the scheduler remains off.
- The optional MDM adapter is disabled. The contract and exact vectors are
  approved and fixture-tested, but pg-mdm 0.11.0 does not provide the M1 policy
  projection or occurrence mapping required for live qualification.
- Ordinary rule, decision, policy-set, lifecycle, retry, comparison, and
  consequence semantics are unchanged.

The runtime image is pinned to
`ghcr.io/trickle-labs/pg_trickle@sha256:4c3a79a6c9f5913c13779a0e005ff69eb561dce5420939e3f9f68dd647278406`.
The image reports PostgreSQL 18.3; that is the explicit v0.46.0 support
boundary.

See the [migration guide](v0.46.0-migration.md), [support matrix](support-matrix.md),
and [v0.46.0 plan](../plans/v0.46.0.md).
