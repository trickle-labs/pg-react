# pg-react 0.45.0 migration

Stop managed and external workers, take a verified backup, and install the
0.45.0 extension files beside the existing 0.44.0 files.

Apply the adjacent update in the same database:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.45.0';
```

Configure the qualified runtime with trigger CDC and the pg_trickle scheduler
off:

```text
shared_preload_libraries=pg_trickle,pg_react
pg_trickle.cdc_mode=trigger
pg_trickle.enabled=off
default_transaction_isolation=read committed
```

Verify `pg_extension.extversion`, the pg_trickle version, and the runtime
settings before resuming workers. Do not enable Graph V1, Delta V1, WAL CDC, or
the pg_trickle scheduler.

The 0.45.0 runtime image is pinned to the published pg_trickle 0.98.0 digest,
but that image reports PostgreSQL 18.3. Do not claim PostgreSQL 18.4 image
qualification until its immutable image identity is verified.
