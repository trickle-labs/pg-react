# pg-react MDM adapter 0.50.0 — synthetic demo preview

**This is a demo release, not a production-supported release.** It lets you try the optional MDM adapter's shadow and operations examples with synthetic data. Do not connect it to a real workload or enable live controls.

## What you can try

- A shadow rehearsal compares seeded synthetic cases under current and proposed policies, then saves the membership, full comparison, coverage counts, and hashes.
- The SQL demo shows operational signals for populated and no-sample fixtures, including pending publication and entity visibility.
- CI retains focused clean-clone and logical-restore checks using test data.

## How to try it

- Follow the [synthetic local exercise](v0.50.0-operations.md#synthetic-local-exercise).
- Or run the **v0.50.0 candidate validation** workflow in `rehearsal` mode, then inspect `synthetic-shadow/` and `qualification-result.json` in its evidence artifact.

The query pack depends on the unpublished pg-mdm 0.15.0 candidate contract v4. Do not install it against the released pg-mdm 0.14 package.

## Limits

- No real workload or cohort was qualified.
- No production operating limits or supported deployment profile are claimed.
- The candidate result is `release_qualified: false`. A green rehearsal means the demo checks passed; release qualification remains blocked.
- This preview contains source and rehearsal evidence, not an installable pg-mdm package or a published container image.
