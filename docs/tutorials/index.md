# Tutorials

[Documentation home](../index.md)

These lessons teach pg-react by building a small, observable system. Each gives you a fixed goal and a sequence to follow, so you can see a successful result before making design choices of your own. Use a disposable database and complete the first lesson before moving to the richer order-review scenario.

| Lesson | You will build | What to know first |
| --- | --- | --- |
| [Your first rule](../getting-started.md) | A high-risk order condition and a durable review task. | Basic SQL; Docker with Compose. |
| [Review marketplace orders](../order-review-tutorial.md) | A policy with lifecycle changes, routing decisions, applicability, retries, and comparison. | The first-rule lesson and its vocabulary. |

After a lesson, try explaining the result in your own words: which fact changed, which match changed, and which work item ran? [Concepts](../concepts.md) helps connect those observations. When you are ready to adapt the example to your own application, switch to the [how-to guides](../how-to/index.md), which leave the design choices with you.
