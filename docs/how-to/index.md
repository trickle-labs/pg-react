# How-to guides

[Documentation home](../index.md)

Choose a guide by the outcome you need. These procedures assume that you understand a condition relation, a declaration, and durable work; if those are new, begin with [Your first rule](../getting-started.md). The examples use public interfaces and stable names so that you can adapt them to your own objects.

| Goal | Guide |
| --- | --- |
| Install a supported runtime or configure an existing server | [Installation](../installation.md) |
| Define rules, consequences, decisions, and policy membership | [Authoring rules and policies](../authoring.md) |
| Compare a proposal and replace a policy safely | [Changing policies safely](../changing-policies.md) |
| Explain a present, absent, or changed result | [Explain an outcome](../explaining-outcomes.md) |
| Diagnose backlog, retry work, or recover a lease | [Operations](../operations.md) |
| Separate authors, readers, operators, and workers | [Security](../security.md) |
| Prepare backups and restore durable state | [Backup and restore](../backup-restore.md) |
| Change the installed extension version | [Upgrade](../upgrade.md) |
| Resolve a symptom or a finding code | [Troubleshooting](../troubleshooting.md) |

For exact parameter types and configuration bounds, use [Reference](../reference/index.md). For the reasoning behind a procedure, use [Explanation](../explanation/index.md). This separation keeps a task guide focused while giving you a place to investigate the deeper question.
