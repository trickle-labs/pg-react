# pg-react 0.45.0 release notes

pg-react 0.45.0 qualifies the pg_trickle 0.98.0 integration boundary.

- The qualified boundary is PostgreSQL 18.4, pgrx 0.18.0, Linux `amd64`, and
  `READ COMMITTED`.
- pg_trickle uses trigger CDC. Its scheduler remains off, and pg-react keeps
  explicit refresh coordination.
- Graph V1 and Delta V1 remain experimental and disabled.
- Rule, decision, policy-set, lifecycle, retry, comparison, and consequence
  semantics are unchanged.

The pinned upstream pg_trickle 0.98.0 image digest is
`sha256:383381c24af9fc43eadbf17429e89906527789942938f2da10861c9c5ffdcc5f`.
That image reports PostgreSQL 18.3. A verifiable PostgreSQL 18.4 image
identity is unresolved and remains an adoption-blocking artifact gap.

See the [migration guide](v0.45.0-migration.md) and [support matrix](support-matrix.md).
