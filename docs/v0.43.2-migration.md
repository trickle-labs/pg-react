# pg-react 0.43.2 migration

The adjacent upgrade is from pg-react 0.43.1:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.43.2';
SELECT extname, extversion FROM pg_extension
WHERE extname IN ('pg_react', 'pg_trickle') ORDER BY extname;
SELECT pgreact.doctor();
```

The migration preserves deployed declaration digests and the 0.43.1
compatibility entry points. New declarations use canonical PostgreSQL
identities. Re-preview declarations after the upgrade when a review token was
created before the source-fingerprint format changed.

If roles are configured, the migration reapplies the documented role matrix
and removes the managed entries from superseded configured roles. Independent
membership grants remain effective. Back up first and run the 0.43.2
qualification runner in staging before production.
