# pg-react 0.11.0 — explainability and reasoning UX

`doctor` provides ordered read-only operational diagnostics. New `explain` overloads expose common envelopes for derived facts, matches, jobs, and program graphs while preserving the M13 rule explanation. Authors can declare typed derived relations and deploy programs without manually listing positive derived dependencies, components, or strata. An explicit advanced reader owns the immutable inspection boundary.

The supported migration is `0.10.0 -> 0.11.0`; all prior runtime, key, worker, recovery, and external-effect limits remain unchanged.
