# pg-react 1.0 release notes

> **Status:** Deferred candidate record (`1.0.0-rc.1`)

This candidate records the M34 / extension `0.31.0` baseline. The project has
postponed `1.0.0` and its complete feature freeze indefinitely. It will define a
new release-candidate sequence only after sufficient user traction and an
explicit maintainer readiness decision.

M35 and later milestones are not part of this candidate record. Development
continues one milestone at a time under separately defined release gates.

## Highlights

- **M34 candidate feature set**: Preserves the complete reactive rule engine, decision programs, policy sets, and continuous derivations established in M0–M33, together with the bounded read-only comparison simulation delivered in M34.
- **Dynamic Managed Runtime Version Support**: Managed background workers dynamically accept `0.31.0`, `1.0.0-rc.N`, and `1.0.0` extension versions, ensuring uninterrupted worker execution across upgrade paths.
- **Authoritative Role Security Boundary**: `pgreact_api.configure_roles(...)` authoritatively configures permissions across the five application roles (`pgreact_author`, `pgreact_operator`, `pgreact_worker`, `pgreact_reader`, `pgreact_advanced_reader`), granting `EXECUTE` on `pgreact.compare` and `pgreact.compare_results` to author, operator, and reader while revoking execution from worker, advanced reader, and PUBLIC.
- **Disambiguated Declaration Deployment**: Re-deploying removed declarations and authoring new rules cleanly avoids PL/pgSQL variable collisions.
- **Safe Claim Bounds**: PostgreSQL-managed worker cycles cap job claims to `least(batch_size, 100)` items, safely respecting the `1..100` public work-claim limit even when `pg_react.batch_size` is configured higher.

## Supported environment

- **PostgreSQL**: `18.3`
- **pg_trickle**: `0.81.0`
- **Platform**: Linux `amd64`

## Installation and upgrade

- **Fresh Install**:
  ```sql
  CREATE EXTENSION pg_trickle;
  CREATE EXTENSION pg_react VERSION '1.0.0-rc.1';
  ```
- **Direct Upgrade from 0.31.0**:
  ```sql
  ALTER EXTENSION pg_react UPDATE TO '1.0.0-rc.1';
  ```
- **Rollback**: Physical filesystem restore / PITR to the pre-upgrade backup snapshot.
