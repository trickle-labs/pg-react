# pg-react 0.43.2 release notes

pg-react 0.43.2 is the M54 correctness patch over 0.43.1. It hardens the
ordinary declaration workflow without changing the stored 0.43.1 artifacts.

- Role grants are synchronized idempotently during install, upgrade, and role
  rotation. Recreated restricted entry points do not retain PUBLIC execute.
- Typed relation and function identities are canonicalized before validation,
  comparison, and source fingerprinting.
- Source checks cover the supported transitive view and function dependency
  closure, including row-level security and SECURITY DEFINER rejection.
- Review and replacement preconditions are checked after the target lock;
  `allow_create`, current digests, plan digests, and explicit old-work policy
  are never silently ignored.
- Rule and decision comparison reads both declarations from the same caller
  snapshot. Package ordering is bounded and package preview blocks changed
  child declarations instead of reporting KEEP.

Upgrade from 0.43.1 with:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.43.2';
```

See [the migration guide](v0.43.2-migration.md) for the compatibility and
qualification notes.
