# pg-react MDM adapter 0.48.0 release notes

This release adds an optional worker package that submits typed MDM policy
intents through pg-react database consequences. The MDM submission, receipt
correlation, and React work completion share one transaction.

The package supports `ASSIGN_QUEUE`, `SET_DUE_AT`, and materialized
`ESCALATE` candidates. It stores immutable request keys and bodies, retries
with the original request, checks active bindings, and records MDM receipts.
Version 0.49.0 adds time-only reevaluation for overdue cases.

A joint run passed against pg-mdm 0.14.0 on PostgreSQL 18.4 with pg-react
extension 0.46.0 and pg-trickle 0.108.0. It used an earlier, uncommitted
pg-react source snapshot. The current source passed the codec and restore
checks, but could not rerun the M2 worker and security checks because the
upstream E2E image lacks the `policy_qualification` fixture. T48.01-T48.11 and
the retention approval remain open. See the
[qualification evidence](../tests/integrations/pg-mdm/evidence/v0.48.0.md)
for image digests, commands, and open gates.

The adapter remains optional and requires explicit binding enablement. The
core PostgreSQL extension version remains 0.46.0. This candidate does not
approve a production cohort or define production-scale operating limits.
Follow the [adapter installation guide](../integrations/pg-mdm/README.md) for
the install order and role setup.
