# pg-react 0.46.0 migration

Stop managed and external workers, take a verified backup, and install the
0.46.0 extension files beside the existing 0.45.0 files.

Apply the adjacent update in the same database:

```sql
ALTER EXTENSION pg_react UPDATE TO '0.46.0';
```

Use the qualified PostgreSQL 18.3 / pg_trickle 0.108.0 runtime profile:

```text
shared_preload_libraries=pg_trickle,pg_react
pg_trickle.cdc_mode=trigger
pg_trickle.enabled=off
pg_trickle.differential_max_change_ratio=1.0
default_transaction_isolation=read committed
```

Verify `pg_extension.extversion`, the pg_trickle version, capability report,
and runtime settings before resuming workers. Stable Graph V1.2 and Delta V1.1 may
be enabled upstream, but pg-react retains explicit coordination and does not
call either API. Keep WAL CDC and the scheduler disabled.

The MDM adapter remains disabled. The approved `MDM-STEWARDSHIP/1` fixture does
not replace live pg-mdm M1 qualification; do not enable policy effects until
the authorized policy projection and occurrence mapping are installed and
qualified.
