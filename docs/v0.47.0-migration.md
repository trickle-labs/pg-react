# v0.47.0 read-only adapter migration

Install the five adapter SQL files after the signed MDM policy projection is
available, in this order:

```text
integrations/pg-mdm/sql/policy-inputs.sql
integrations/pg-mdm/sql/routing.sql
integrations/pg-mdm/sql/deadline-preview.sql
integrations/pg-mdm/sql/comparison.sql
integrations/pg-mdm/sql/typed-flow.sql
```

The adapter does not alter an MDM schema. Grant the runtime reader only
`SELECT` on the authorized projection and keep MDM intent submission absent.
Publish a package with `pgreact_mdm.publish_package`, review the returned
`policy_document`, and run the existing pg-react declaration review flow before
using the package for shadow evaluation.

Every comparison must provide an explicit captured evaluation time and a fixed
population with either an exact membership list or a key range plus expected
count. A `partial` result is not a whole-population safety claim.

The package is read-only by construction: it has no MDM write calls and its
comparison function reports zero intent, work, lifecycle, refresh, and MDM
writes. The `mdm_fixture` showcase is qualification-only; do not install it in
the `mdm_steward` namespace.
